### Task 2: Setup Root Swift Package (Option 3)

**Files:**
- Create: `Package.swift`

- [ ] **Step 1: Create root Package.swift**
```swift
// swift-tools-version: 5.9
import PackageDescription

let package = Package(
    name: "splitspeak",
    platforms: [.iOS(.v17)],
    products: [
        .library(name: "SCTCore", targets: ["SCTCore"])
    ],
    targets: [
        .target(name: "SCTCore", path: "Modules/SCTCore/Sources"),
        .testTarget(name: "SCTCoreTests", dependencies: ["SCTCore"], path: "Modules/SCTCore/Tests")
    ]
)
```

### Task 3: Setup XcodeGen (project.yml)

**Files:**
- Create: `project.yml`

- [ ] **Step 1: Create project.yml**
```yaml
name: splitspeak
options:
  bundleIdPrefix: fun.withus
targets:
  splitspeak:
    type: application
    platform: iOS
    deploymentTarget: "17.0"
    sources: [App]
    dependencies:
      - package: SCTCore
    settings:
      DEVELOPMENT_TEAM: YOUR_TEAM_ID # To be replaced by user or via env
  SCTCore:
    type: framework
    platform: iOS
    sources: [Modules/SCTCore/Sources]

packages:
  SCTCore:
    path: .
```

- [ ] **Step 2: Create App source placeholder**
Create `App/splitspeakApp.swift` and `App/ContentView.swift`.

- [ ] **Step 3: Run XcodeGen**

### Task 4: Setup Justfile for CLI Workflow

**Files:**
- Create: `justfile`

- [ ] **Step 1: Create justfile**
```just
generate:
    xcodegen generate

build:
    xcodebuild -project splitspeak.xcodeproj -scheme splitspeak -destination 'generic/platform=iOS' build

test:
    swift test

test-ios:
    xcodebuild test -project splitspeak.xcodeproj -scheme splitspeak -destination 'platform=iOS Simulator,name=iPhone 15'

clean:
    rm -rf splitspeak.xcodeproj
    rm -rf .build
```

- [ ] **Step 2: Verify just commands**
Run: `just generate`, `just test`
Expected: Success.

- [ ] **Step 3: Commit**
Run: `git add . && git commit -m "chore: setup build and test workflow with just and xcodegen"`
